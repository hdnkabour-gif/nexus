# Règles communes à toutes les fiches d'essai

## Avant de commencer
- **Données fictives uniquement.** N'utilisez jamais un vrai client, une vraie CIN, un vrai permis, une vraie facture ni un vrai numéro de téléphone.
  *Darija : استعمل غير معلومات تجريبية، ماشي ديال الكليان الحقيقيين.*
- Noms de test : `TEST Client 01`. Téléphones : `+212 600 000 001 (TEST)`. Plaques : `TEST-01-A`.
- Ne faites pas de capture d'écran qui montre une vraie personne. Ne partagez pas votre mot de passe, même avec nous.

## Comment noter un résultat
Pour chaque ligne, cochez une seule case :
- ✅ **Ça marche** : le résultat attendu s'affiche.
- ❌ **Ça ne marche pas** : notez ce que vous avez vu.
- ❓ **Pas clair** : notez ce qui vous a bloqué ou ce qui était difficile à comprendre.

Ces fiches servent à tester l'application, pas à l'utiliser pour votre vrai travail.
*Darija : هاد التجربة باش نشوفو واش البرنامج كيخدم مزيان، ماشي باش تخدم بيه بصح دابا.*

## À la fin de l'essai
1. Notez la facilité d'utilisation, de 1 (très difficile) à 5 (très facile) : ___

4. Qu'est-ce qui vous empêcherait d'utiliser l'application tous les jours ? ___

Envoyez vos réponses par le canal convenu, avec votre code d'essai. N'y mettez pas de vraies données de vos clients.
